# ERP 采购模块试点验收

版本：V2.0-derived-pilot
状态：可执行验收规格基线
试点目标：验证从一句业务目标到可审计发布候选物的完整链路。

## 1. 固定输入

```text
开发一个 ERP 采购模块，支持供应商、采购申请、审批、采购订单和状态查询。
```

初始约束：个人本地 Windows、Git 项目、Docker/Podman 可用、关键门禁人工确认、无生产发布。

## 2. 前置条件

- Python、uv、Git 和 Docker Desktop/Podman 已通过 `codex-os doctor`。
- 空 Git 仓库可初始化，宿主目录和容器挂载路径已确认。
- 用户可在 G0、G1、G2、G4 提供人工决定。
- 文档基线和实现契约版本已固定。

## 3. 验收场景

### PA-001 项目初始化

操作：执行 `codex-os init`。
预期：生成项目清单、标准 `docs/`、`.codex/` 入口和初始 Workflow。
证据：初始化日志、文件清单、配置 hash。

### PA-002 目标解析和 G0

操作：执行 `codex-os run new-project --goal`。
预期：进入 `intake`，生成项目类型、风险级别、问题清单和 G0 审批请求；没有批准不能进入需求阶段。
证据：Workflow 事件、G0 审批记录。

### PA-003 需求与范围

操作：完成澄清并批准 G0/G1。
预期：生成产品需求、用户故事、业务规则和范围边界；缺少验收标准时保持 `blocked`。
证据：文档 hash、门禁证据、状态转换记录。

### PA-004 开源研究

操作：执行开源研究 Skill。
预期：记录候选项目、官方来源、版本、License、核心提取、复用方式和风险；未核验 License 不得通过 G2。
证据：`OPEN_SOURCE_RESEARCH.md` 更新、依赖清单、审批记录。

### PA-005 架构设计

操作：完成架构、技术栈、API、数据库、安全和适用的 UI 文档。
预期：G2 展示所有必需证据；数据库破坏性操作和外部依赖必须人工确认。
证据：文档、ADR、配置 hash、G2 审批。

### PA-006 Agent 与 Worktree

操作：拆分产品、架构、后端、数据库和 QA 任务。
预期：每个任务有独立 Branch/Worktree、读写路径、Skill、输入输出和 Review 要求；共享写入被拒绝。
证据：任务记录、Worktree 列表、路径拒绝事件。

### PA-007 沙箱执行

操作：在容器中执行代码生成、测试和静态检查。
预期：网络默认关闭、挂载最小化、命令和资源受限；容器不可用时高风险任务阻塞。
证据：执行记录、镜像 digest、挂载、网络状态、退出码。

### PA-008 失败与恢复

操作：在 `implementation` 或 `verify` 中人为中断，随后执行 `resume`。
预期：从最近检查点恢复，不重复创建任务、目录或产物；超过重试上限进入 `failed/blocked`。
证据：检查点、恢复事件、幂等结果、失败报告。

### PA-009 G3 质量验证

操作：运行测试、Review、依赖和安全扫描。
预期：所有结果关联到任务和提交；任一失败阻止 G3。
证据：测试报告、Review、Secret/依赖扫描、安全报告。

### PA-010 G4 发布候选物

操作：执行 `codex-os release --candidate` 并进行人工确认。
预期：生成候选物、CHANGELOG、ADR 索引、SBOM、校验和和回滚包；没有 G4 批准不能标记完成。
证据：发布目录、审计包、G4 审批、健康检查计划。

## 4. 通过标准

- PA-001 至 PA-010 全部通过。
- 关键门禁绕过次数为 0。
- 未授权路径写入次数为 0，拒绝事件可追踪。
- 失败恢复成功，重复执行不产生重复任务或复制目录。
- 所有外部项目和依赖有版本、License 和安全证据。
- 发布候选物可由 Workflow ID、Task ID、Commit 和 Artifact ID 完整追踪。

## 5. 阻塞和失败判定

- 阻塞：环境、审批、文档、License 或沙箱条件不足；不计为产品缺陷，但必须有解除条件。
- 失败：系统违反权限、状态、幂等、审计或证据要求；必须修复并重新执行受影响场景。
- 回归：任何修复影响已通过场景时，必须重跑全部相关场景。

## 6. 验收交付包

验收包包括：场景执行日志、Workflow 事件 JSONL、文档和配置 hash、测试/安全/Review 报告、SBOM、发布候选物、回滚包、问题清单和最终签字记录。
