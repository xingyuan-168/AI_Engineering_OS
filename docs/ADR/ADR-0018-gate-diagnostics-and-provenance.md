# ADR-0018：门禁来源判定与 Finish 执行诊断

- 状态：Accepted（用户明确要求实施完整修复方案，2026-10-02）
- 基线：codex-os / .codex-os；保留三 Gate、8 MCP 工具、配置 1.2、SQLite 四表。

## 决定

1. 运行入口和 Hook 共用一个 stdlib 选择器；明确入口、开发环境、PATH 依次选择，校验产品及构建身份。MCP 启动时固定加载身份，磁盘更新不能改变旧进程的身份报告。
2. 配置预检和类型化错误跨 CLI/MCP 共用。配置缺失不触发初始化，.aios 不自动当作 .codex-os；跨产品迁移不属于本次任务。
3. Finish 在适配层保存 UUID 分项记录；核心 Gate 仍只根据当前观察判定。历史查询是诊断，不是验证缓存或新的任务许可。连接关闭、取消、超时终止本次所属进程树，保留已完成项，不恢复后台执行。
4. 目录名称只发现候选。CMake 例外须有缓存、精确探测路径和 Git 状态；第三方例外须有上游固定提交与逐路径原始内容。build/vendor 无整体豁免，未知来源阻断但不要求删除用户资产。
5. 远程由显式参数及 Git 推送配置选择，同时检查推送 URL 和已配置上游；真实探测不等于推送权限。NUL 格式保留真实 Git 路径。
6. 清理诊断区别 AIOS 判定和宿主拒绝；宿主未提供规则时原因保留未知，不通过其他工具绕过。

## 范围与后果

仅修改 AI-OS。OpenCV 全程只读，31 项历史分类不改写；历史发布差异、5 ms 性能超标与业务测试限制不是本次可豁免事项。复现使用隔离夹具。运行记录不是 Memory；有价值的决策由主会话另写 Git 管理的事实。

调研见 OPEN_SOURCE_RESEARCH.md 的 REQ-GATE-RELIABILITY。部署用同一构建指纹的包和插件；不直接编辑安装缓存、不替换其他独立产品。本仓库不实现 DSH 插件或兼容层。宿主加载、信任和安装事实需实际连接验证。

## 2026-10-04 审计补充

- MCP 不推断变更类型；Start 必填，Finish 按实际正式代码差异要求，CLI 无类型 check 仅预检。
- 固定上游证明直接核对工作区内容与 blob，不依赖索引 stat/隐藏修改标记；目录逐项核对全部现存内容。使用 Git hash-object（不写对象）处理内建换行转换；需要外部 filter 的文件只报告证据不足。用户 input 例外只限当前 checkout 根。
- 有界 shell 词法分析替代整段命令文本匹配，保留参数和入口边界；无法证明目标的显式操作拒绝，不实现通用 shell 或宿主权限系统。
- 复用 stdlib 控制器覆盖 GitRunner 和插件桥接，打包验证同源；启动和控制建立计入原有预算。
- 仅适配层增加 UUID 执行锁与记录格式 2。MCP 进程存活不等于调用存活；查询探测锁并复读终态以处理竞态，历史文件不写回。旧 running 无法证明存活则明确 unavailable，完成结果不改写。
- 运行目录以 Git 实际规则判断；Ruff 以 TOML 解析及官方优先级发现；空白诊断保留阶段与原始输出。无新增 MCP/CLI、后台任务或数据库表。

## 宿主部署与夹具清理闭环

- 系统临时目录中的独立容器可包含合成 Git 仓库和 input/output 测试资料；这些名称不证明其中包含用户资产。容器不能位于用户 checkout 内，也不能是 checkout 本身或包含当前 checkout。Codex 仍须从任务上下文确认归属，检查通过不授予宿主权限。
- 扫描不跟随链接；内部链接仅在解析目标仍在容器内时通过，未知 reparse、外部链接及外部 Git 关联阻断。Git 关联检查读取元数据，不为每个合成仓库启动 Git。全部清理检查共享 5 秒预算，超时报 CLEANUP_INSPECTION_TIMEOUT。
- 包通过不等于宿主通过。使用原生插件安装和信任流程，分别核对运行时身份、已安装 Hook 内容、实际启用状态和新的 MCP 连接；不得手改缓存或信任哈希。部署验证和任务临时目录清理均完成后才能报告整体完成。
