# 测试计划

## 测试层级

- 单元：配置模型、状态转换、门禁、影响检查、路径和命令策略。
- 集成：CLI、SQLite、Git/Worktree、Skill/Agent 调度和产物索引。
- 端到端：ERP 采购模块从目标输入到发布候选物。
- 安全：Secret、依赖、命令、路径、License 和敏感日志检查。

## 必测场景

1. 新项目缺少范围时被阻止进入设计。
2. 功能修改影响 API/数据库时生成正确检查项。
3. 任务失败后从检查点恢复，不产生复制版本目录。
4. Agent 写入未授权路径时失败并记录事件。
5. 未确认 License 的依赖不能通过 G2。
6. 缺少测试、Review 或安全证据时不能通过 G4。
7. 多个 Worktree 合并时冲突可识别、可暂停和可人工解决。

## 质量门禁

提交前通过单元测试、lint、类型检查和 Secret 扫描；合并前通过集成测试和 Review；发布前通过端到端、依赖安全和文档完整性检查。
