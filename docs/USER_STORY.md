# 用户故事

## US-001：从目标创建项目

作为个人开发者，我希望输入一句业务目标后自动建立项目文档和 Workflow，以便快速开始而不遗漏工程基础。

验收：生成项目清单、范围、需求、初始任务和待确认问题。

## US-002：查看和恢复流程

作为用户，我希望看到当前阶段、阻塞原因和下一步，并能从检查点恢复，以便处理中断和失败。

验收：显示状态、事件、产物、审批和最近检查点；恢复不重复产生版本目录。

## US-003：开源复用决策

作为技术负责人，我希望看到候选项目的核心、License、成熟度和复用方式，以便避免重复造轮子和合规风险。

验收：每个候选项目有版本、来源、分析结论和 ADR 引用。

## US-004：隔离 Agent 任务

作为开发者，我希望每个 Agent 在独立 Worktree 中工作，以便并行开发不覆盖彼此修改。

验收：任务具备独立分支、允许路径、产物和 Review 记录。

## US-005：受控执行

作为用户，我希望系统在执行命令前检查风险，并对不可逆操作要求确认，以便保护项目和数据。

验收：dry-run、allowlist、路径限制和审批日志均可验证。

## US-006：完整发布证据

作为 Reviewer，我希望发布候选物包含测试、Review、安全和变更记录，以便判断是否可以发布。

验收：G4 门禁缺少任一证据时不能完成。
