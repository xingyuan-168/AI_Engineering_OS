# 执行策略

版本：V2.0-derived-execution
状态：可执行实现规格基线
默认：由 `.codex-os/execution-policy.yaml` 选择 Docker 或 Podman OCI 沙箱；当前仓库选择 Podman。Windows 宿主机不直接承载高风险 Agent 命令。

## 1. 沙箱前置条件

- 策略所选的 Docker Desktop 或 Podman machine 已安装、启动并可由当前用户调用；两种 Adapter 必须执行相同安全契约。
- 镜像必须来自已批准的来源，并使用固定 digest 或锁定版本。
- 容器不可用时，低风险只读检查可报告环境问题；代码写入、网络访问、迁移、删除和发布全部进入 `blocked`。
- Plugin 和项目配置不能改变上述降级规则；Codex Host 也必须经 Runtime 进入执行策略。

## 2. 挂载规则

| 挂载 | 容器权限 | 说明 |
| --- | --- | --- |
| 当前 Worktree | 读写 | 仅限 `.worktrees/<workflow-id>/<agent-name>/<task-id>/` 当前 Agent 任务路径 |
| `artifacts/` | 读写 | 产物和报告输出 |
| 依赖缓存 | 只读或受控读写 | 不得包含 Secret |
| 宿主项目根目录 | 不挂载 | 防止越权访问其它 Worktree |
| 用户目录、凭据目录 | 不挂载 | 默认禁止 |
| Docker socket | 不挂载 | 防止容器逃逸 |

挂载前对路径执行绝对路径解析、根目录边界检查、Worktree 归属检查和符号链接检查。

## 3. 网络和凭据

- 网络默认关闭。
- 开源调研或依赖下载必须声明目标、时长和代理策略，并经过审批。
- 不把宿主环境变量整体传入容器；只传入策略允许的非敏感变量。
- Token、密码、私钥和云凭据不得写入任务输入、日志、Memory 或产物。
- 日志中对疑似 Secret 执行脱敏，原始 Secret 不保留。

## 4. 命令风险等级

| 等级 | 示例 | 默认行为 |
| --- | --- | --- |
| L0 | `git status`、读取文件、静态检查 | 容器内自动执行 |
| L1 | 单元测试、格式化、构建 | 容器内自动执行，设置超时 |
| L2 | 安装依赖、网络访问、生成迁移 | 容器内执行，需审批或已批准策略 |
| L3 | 删除、数据库迁移、修改权限、外传数据 | 必须人工确认 |
| L4 | 生产发布、宿主机写入、凭据访问 | V1 禁止自动执行，必须人工确认和专项流程 |

默认阻止：宿主机路径写入、递归删除、系统关机/重启、修改防火墙、访问 Docker socket、未经批准的网络外传和任意 shell 拼接。

## 5. 资源限制

每个容器默认：CPU 2 核、内存 4 GB、临时磁盘 10 GB、进程数 256、单命令 30 分钟、单任务 2 小时。超限后停止任务并记录 `EXECUTION_LIMIT_EXCEEDED`。

## 6. 取消和终止

- 用户取消先停止当前子进程，再停止容器，最后写入终止事件。
- 强制终止保留 stdout、stderr、退出码、容器 ID 和最后检查点。
- 终止后的 Worktree 标记为脏状态，必须人工检查后才能复用。

## 7. 审计记录

每次执行记录命令摘要、参数 hash、工作目录、挂载、镜像 digest、网络状态、开始/结束时间、退出码、输出日志和审批引用；禁止只记录“成功/失败”。

## 8. 完成定义

执行策略只有在沙箱不可用阻塞、挂载越界拒绝、网络默认关闭、L0-L4 风险分类、资源限制、Secret 脱敏、取消和审计记录均有测试时才算完成。
