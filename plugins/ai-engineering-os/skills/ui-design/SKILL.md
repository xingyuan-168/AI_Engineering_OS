# UI design

Use the project's existing design system when present. Define component anatomy, layout, responsive breakpoints, typography, color roles, spacing, content behavior, and every interaction state required by the approved flow. Prefer reusable tokens and components over page-specific exceptions.

Check contrast, focus visibility, target size, zoom and reflow, semantic structure, and reduced-motion behavior. Do not encode missing requirements as visual assumptions. Hand off exact states, component variants, assets, accessibility notes, source links, and acceptance checks within the task's allowed paths.
